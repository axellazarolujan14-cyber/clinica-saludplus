# 🏥 Clínica SaludPlus

Proyecto web de una clínica médica desarrollado con **HTML, CSS y JavaScript**, publicado con **GitHub Pages**.

## 🌐 Sitio en vivo
👉 [https://axellazarolujan14-cyber.github.io/clinica-saludplus/](https://axellazarolujan14-cyber.github.io/clinica-saludplus/)

## 📋 Características
- ✅ Diseño moderno y responsive
- ✅ Menú de navegación con scroll suave
- ✅ Sección de servicios médicos
- ✅ Horarios de atención
- ✅ Formulario de reserva de citas con validación
- ✅ Animaciones al hacer scroll
- ✅ Botón "volver arriba"
- ✅ Almacenamiento local de citas

## 🛠️ Tecnologías
- HTML5
- CSS3 (Grid, Flexbox, Variables CSS)
- JavaScript (ES6)
- Font Awesome (iconos)
- Google Fonts (Poppins)
